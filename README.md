# DOET-Ch.5-Discussion
#DOET Chapter 5 reading discussion mm621 Part 1 and Part 2
In Chapter Five, Don Norman talks about errors and explains that if we understand that humans will always make mistakes, then instead of blaming them, designers need to account for this and design for error. Norman describes two main kinds of errors: slips and mistakes. Slips can happen at any stage of the seven-stage action cycle because they occur when the user has the correct goal and intention, but something goes wrong in the execution. Mistakes usually happen early in the process because they are about forming the wrong goal or plan in the first place (Norman, 2013, pp. 133 - 141).
One example that stood out to me is how humans are not very good at copying or inputting long strings of numbers, especially when you consider long work days or how tired people can be. Norman mentions how task structure, attention, and environmental factors all make slips more likely (pp. 134 - 141). It made me think about why we design so many systems that require exact numbers, like credit card entry during online purchases. Designers try to prevent accidental purchases through constraints, but at the same time, we need to think about how to design for error so that if someone inputs a number incorrectly, the system helps them recover instead of frustrating them.
